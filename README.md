# Jitterbug

A 3D visualizer for simulating Buckminster Fuller–style jitterbug
transformations. Twist a frame of rigid polygons from fully open to fully
collapsed with a slider, and experiment with different polygon shapes and
build settings.

**Live site:** https://shalinpei.github.io/jitterbug

## Run locally

No install or build step. From the repo folder:

    python3 -m http.server

Then open http://localhost:8000.

## Built with

- Plain HTML, CSS, and JavaScript (ES modules)
- [Three.js](https://threejs.org) for 3D rendering, loaded from a CDN
